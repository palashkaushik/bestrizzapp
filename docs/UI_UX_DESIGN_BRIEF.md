# Document 04 — UI/UX Design Brief

- Aesthetic
  - Dark social-gym, high-contrast, game-like. Empirio clarity + Coach Rizz grit. Use frontend-design + web-design-guidelines + minimalist-ui skills. Avoid generic purple gradients.

- Primary Color
  - #FF3B30 action red for approach CTA (Suggested default, rejection-energy). Secondary ink #0A0A0B.

- Background Color
  - #0B0D10 dark base, cards #15181D, borders #262B33 (Suggested default for night training vibe).

- Text Color
  - Primary #F5F7FA, muted #9AA4B2, success #22C55E, XP gold #FACC15.

- Accent / CTA Color
  - CTA #FF3B30, XP/reward #FACC15, streak flame #FF6B00. Rejection logged = gold burst (gsap).

- Font
  - Inter Tight for headings + Inter for body via fontsource (Suggested default, free, fast on Pages). Mono: JetBrains Mono for scores.

- Border Radius
  - 14px cards, 999px pills/buttons, 10px inputs (Suggested default).

- Shadows
  - Soft: 0 8px 30px rgba(0,0,0,.35). CTA glow: 0 0 0 1px rgba(255,59,48,.4), 0 8px 24px rgba(255,59,48,.25). No heavy neumorphism.

- Dark/Light Mode
  - Dark default only v1 (Suggested default, halves design QA). Light later via CSS vars.

- Reference Apps
  - Empirio (interactive decision cards, pattern profile), Coach Rizz (Week 1/4/12, rejection=XP), Duolingo (streaks, XP bar), Rizzry (Rizz Score card).

- Mobile
  - Mobile-first 360px, bottom tabs, thumb-reach CTA, video player 16:9 sticky, log-mission <10s, PWA-ready manifest. Test 360x740 + desktop 1440.
