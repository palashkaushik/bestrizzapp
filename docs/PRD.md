# Document 01 — PRD (Product Requirements Document)

- App Name
  - Best Rizz App

- Tagline
  - Turn approach anxiety into god-level confidence, one real rep at a time.

- Problem
  - Men know what to do socially but freeze before acting. Dating advice is theory-heavy, video-only, or AI-chat-only with no real-world reps. No app combines Empirio-style interactive video lessons + action missions + AI practice + measurable confidence profile in one web-first loop.

- Target User
  - 18-32 men, shy to intermediate, learning pickup/social confidence. Web-first, mobile browser usable. Wants game-like structure, not lectures. (Suggested default: solo founder MVP targets English-speaking indie audience, web only for v1)

- Core Features (Must Have)
  - 1. Interactive video lessons (Empirio-style): short video + context + make-your-call + reveal outcome + pattern insight
  - 2. Action missions ladder: Week 1 ask-for-time → Week 4 40 approaches → Week 12 autopilot, with XP, double XP for rejection logged
  - 3. AI conversation practice: friendly → hard personas, scored on questions, talk balance, follow-ups, vibe
  - 4. Case library: real interaction breakdowns with choices and second-order effects
  - 5. Confidence profile: 10 dimensions + Rizz Score + streaks + level (Beginner → Intermediate → Expert → God-level)
  - 6. Auth + progress persistence across devices

- Nice to Have
  - Field reports feed, leaderboards, curated case arcs, daily streak reminders, tone control (playful/classy/bold), analytics on openers, PWA install

- Out of Scope
  - Native iOS/Android apps for v1 (web only), live video coaching, dating-app integration (Tinder/Hinge API), paid subscriptions v1, user-generated video uploads v1

- User Stories
  - As a shy beginner, I can watch a 2-min interactive video lesson and make a choice so I learn without freezing.
  - As a trainee, I can log an IRL approach in 10 seconds and earn XP (2x for rejection) so fear becomes fuel.
  - As a user, I can practice with AI personas and get a score so I am ready before real approaches.
  - As a returner, I can see my Rizz Score, streak and 10-dimension profile so I track transformation.
  - As a mobile user, I can complete a mission from my phone browser so I train in the field.

- Success Metrics
  - D1 retention >35%, W4 mission completion >20%, median approaches/user/week >3 by week 4, video-lesson finish rate >70%, AI practice sessions/user/week >2
